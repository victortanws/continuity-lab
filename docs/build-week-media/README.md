# OpenAI Build Week media

This folder contains the recommended screenshots for the Continuity Lab and
Vibe Code Simulator submission. The `primary` folder is the main submission
set. The Slap the Heavens image is optional supporting context rather than a
second submitted product.

## If the submission form allows only a few images

Use images **1, 4, and 6**. Together they show the playable project, the actual
continuity diagnosis, and the working ChatGPT integration. Add image **2** when
there is room for a fourth image because it explains why the $47,000 question
matters emotionally. Use the Slap the Heavens image only after the primary
product story is already clear.
